# Security

Snaplane is a local macOS menu-bar app. It asks for **Accessibility** so it can move windows into zones.

Do not commit anything under `signing/`, `*.p12`, `*.cer`, or `*.keychain-db`. Those are machine-local code-signing identities.

To report a vulnerability, open a [private security advisory](https://github.com/Astucore-ai/snaplane/security/advisories/new) or contact the org owner via GitHub. Do not file a public issue for a live exploit.
